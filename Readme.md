# Projet1 openclassroom

Notebook d’analyse exploratoire et de modélisation (Random Forest, régression linéaire, Gradient Boosting, etc.) sur les données de benchmarking énergétique 2016 de la ville de Seattle.

## Prérequis

- Python **3.10+** 


## 1. Créer et activer l’environnement virtuel

```bash
# Créer l’environnement
python -m venv .venv

# Activer (Linux / macOS)
source .venv/bin/activate

# Activer (Windows – PowerShell)
.venv\Scripts\Activate.ps1

# Activer (Windows – cmd)
.venv\Scripts\activate.bat
```


## 2. Installer les dépendances

```bash
pip install -r requirements.txt
```
## 3. Lancer le projet
 ```bash
jupyter notebook
```
